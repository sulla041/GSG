## 正式样本目录

正式数据集使用图对目录，而不是输入图和标签的松散并列目录：

```text
pair_root/<pair_id>/
  input/graph.json
  output/graph.json
  mapping/node_map.json
  mapping/relation_map.json
  conditions.json
  provenance.json
```

`pair_id` 由 `design_id`、输入 stage、输出 stage、corner、mode、library_hash 和 flow_hash 决定。`output/graph.json` 内嵌目标属性，原始 ODB/DEF/SPEF/report 通过 `provenance.json` 回溯。

## 数据流

```text
CircuitNet RTL / local design
  -> Yosys: pre-map JSON, mapped netlist, G_logic_pre_map, G_mapped_cellpin
  -> OpenROAD: floorplan, placement, CTS, GCell, route, DEF, ODB, SPEF
  -> graph extraction: G_place, G_gcell, G_route, G_rc
  -> OpenRCX + OpenROAD built-in STA/power: RC, cell arc, net delay, pin timing, setup/hold and power metrics
  -> pair builder: G -> G', node/relation mapping, output attributes
  -> registry manifest: pair, graph, mapping, condition, source hash
```

## 下游任务支持统计

意涵，当前工程定义 9 个正式下游任务：A1、S1、D1、D2、D3、R1、P0、P1、P2。500 子集 9 个任务均已登记；A2 已明确排除，不再进入任务清单。D2 使用 relation-level `net_timing_target`，必须依据 valid mask 使用。

意涵，D1 的训练默认使用 `circuitnet3_v3_03_task_tensors_v2`，而不是旧的 v1。v2 通过 Nangate45 Liberty 校准引脚方向，恢复 `net -> input_pin -> cell -> output_pin -> net` 的信号流，删除 DFS 检出的反馈回边，并增加归一化 logic level；旧 v1 仅保留作回归对照。

意涵，完整流水线已经完成“physical -> map-place -> route/RC -> registry -> task pairs”提交；使用阶段直接读取 task manifest 和阶段 pair manifest，构造阶段的 tmux 会话已清理，所有路径和字段以 `工具指南.md` 的使用说明为准。

## 并行边界

意涵，当前机器为 128 个逻辑 CPU、约 503 GiB 内存；本轮 OpenROAD 使用 `3 x 32` design 级并行并已完成，map-place、route/RC 和 task registry 由 supervisor 串联提交，最终 manifest 已写入。每个阶段仍必须由主进程统一写 manifest，禁止多个 supervisor 同时覆盖同一输出目录。

map-place 和 route/RC builder 会复用已有完整 design 目录，只处理新增或不完整 design；因此每轮 supervisor 是增量流水线，不会重复重建已经提交的 pair。

意涵，当前构造已完成，本项目的 `dac2027-phys` 和 `dac2027-pipeline` tmux 会话已清理；其他项目会话未触碰，最终状态以四个 manifest 和 pipeline latest 快照为准。

## V3.03 稀疏有界几何度量动力学体系

- **核心代码包**：`code/v3_03/`
  - `dense_coords.py`：全实体（Cell/Pin/Net）物理坐标密集化推导算法（Pin 归属继承，Net 重心解析，打通 98.2% 实体密集力场）；
  - `pair_distance.py`：稀疏点对采样器（真边优先 + $\alpha N$ 致密负采样，支持 $\alpha=24$）；
  - `readout.py`：V3.03 原生内生读出头 `IntrinsicReadout`，支持节点独立 2D 空间投影与原生点对基底读出；
  - `interactions.py`：纯张量 GPU 并行 $K$-有界动力学近邻采样（$K=8$ 聚焦因果真边，抑制 30 倍随机噪声稀释）；
  - `model.py`：V3.03 动力学模型，实现节点独立物理投影与无衰减反向传播；
  - `circuit_data.py`：电路张量秒级加载器（带实时进度条回显与显存常驻）。
- **执行脚本**：
  - `script/train_v3_03_dense_node_dist.py`：高密节点独立投影相对物理距离训练与评估主程序；
  - `script/run_v3_03_dense_node_dist_long.sh`：全量 162 芯片 $\alpha=24$ 高密力场长程训练入口；
  - `script/train_v3_03_log_dist.py`：对数空间几何度量动力学训练主程序；
  - `script/run_v3_03_zero_readout_long.sh`：零读出头几何动力学全量长程训练入口。
- **学术调研与 Baseline 库**：
  - `search/baseline_review_2020_2026.md`：2020–2026 年微电子顶会（DAC/ICCAD/DATE 等）预布局线长、坐标定位与电气时序预测（TimingPredict, PreRoutGNN 等）全景对比分析。
- **单文件行数规范**：`code/v3_03/` 下所有 Python 文件单文件行数严格小于 150 行。
