# 行为准则

更新时间：2026-11-06。

1. `for-agent.txt` 是协作约束来源，用户称呼使用“意涵”。
2. 根目录文档描述当前数据集构造状态；数据事实以产物目录和 registry manifest 为准。
3. `hub/GSG` 是独立 Git 工作区，根目录文档更新不改变其中既有文件。
4. 每个数据集样本使用 `design_id/top/clock/library_hash/flow_hash/stage/corner/mode` 关联图、标签和日志。
5. 每个监督值记录单位、valid mask、来源产物、来源 hash 和工具版本。
6. 图特征覆盖逻辑、library、cell、pin、net、placement、route、RC、时钟和 PVT 条件。
7. Yosys 产出逻辑与映射图；OpenROAD/OpenRCX 产出物理阶段图、placement/routing/RC；OpenROAD 内置 STA/power 产出 max/min timing 与图级指标；独立 OpenSTA 只作补充复核。
8. 文档更新同步维护当前资产、当前规模、当前工具路径与当前执行顺序。
9. 代码或数据构造改动完成后执行范围匹配的结构、单位、键关联和覆盖率校验，并记录结果。
10. 正式数据集以 `G -> G'` 图对为基本样本；只有输入图和独立标签而没有输出图的记录，必须标记为外部监督，不计入主数据集。
11. 相邻阶段图必须保存节点映射、关系映射和新增实体标记；跨阶段无法审计对应关系时，保留为独立资产并暂停配对。
12. 全量 CircuitNet 当前先运行 Yosys mapped 网表队列，再运行 OpenROAD physical flow；不能用外部 Final 网表替代本地 RTL 重建结果。
13. 当前综合状态以 `/data/yiyh/dac2027/dataset/circuit/circuitnet3_nangate45_synth_v1/manifest.json` 为准；最终已登记 `5,999/5,999`，其中 `5,965` 个 mapped-ready、`34` 个 mapped-failed。物理状态以 `/data/yiyh/dac2027/dataset/circuit/circuitnet3_nangate45_physical_v1/manifest.json`、pair manifests 和 pipeline latest 快照为准；最终为 `5,965/5,965`，其中 `4,468` ready、`1,497` failed。构造完成后 tmux 会话为空属于正常结束，历史 checkpoint 必须标明采集时点，不能覆盖历史记录。
14. 下游任务统计必须同时报告任务定义数、已有来源产物数、mapping 阻塞数和严格 `G -> G'` pair 数；禁止只报告“支持任务数”而隐藏输出图未完成的事实。
15. 内存安全管控：任何后台脚本、多核数据处理、张量预提取及模型训练任务，所占用的总内存严格不得超过当前机器剩余内存（available memory）的 50%，必须具备并发度控制与防御性内存预算，杜绝因并发过载导致系统卡死或内存溢出。
16. 稀疏图与边表规范：禁止使用密集邻接矩阵（$N \times N$ 稠密张量）处理图，避免 $O(N^2)$ 显存爆炸与计算瓶颈；必须严格采用边表（Edge List，即稀疏源汇节点索引 `edge_index` 与对应边特征）以及复杂度为 $O(N)$（$O(N + E)$ 稀疏物理连接）的线性动力学模式，确保万级乃至百万级节点芯片图在张量化、数据加载及模型前向中均具备极致的内存效率与扩展性。
17. 脚本执行上下文隔离规范：所有位于 `script/`、`test/` 或其他子目录下的独立可执行 Python 脚本，必须在代码最顶层显式将项目根目录解析并插入到 `sys.path[0]`，杜绝因当前子目录优先导致的工作区核心包（如 `code`、`test`）被错误解析或遮蔽的问题。
18. 全实体平等性与刚体不变度量准则：在处理集成电路物理图任务时，禁止将中间媒介（Pin、Net、Port）设为无坐标的绝缘孤点；必须遵循实体平等哲学，Pin 继承 Cell 归属坐标，Net 继承所连 Pin 之几何平均重心，实现全图密集连续物理场。涉及跨芯片空间度量时，禁止直接依赖具有旋转二义性与模式对冲的绝对坐标作为单一监督，应优先采用具备 $E(2)$ 刚体变换不变性的欧氏物理距离与对数空间度量，确保不同流动方向与边界引脚布局下的全局物理规律自洽。
19. 紧凑编码与显存常驻吞吐优化准则：为最大化 GPU 算力利用率，张量缓存构建必须推行紧凑原生类型（离散类别统一使用 uint8，阻抗与时序目标使用 float32），严禁在磁盘与显存中持久化高维稀疏浮点展开；严格禁止在模型前向高频演化内循环中重复执行 argmax、动态查表或度数统计等可离线预计算的逻辑；关系阻抗必须通过源宿索引在节点端切片直连；在显存允许的前提下，优先将全量紧凑样本图预加载并常驻至加速卡显存，彻底消除 Host-to-Device 搬运延迟。
