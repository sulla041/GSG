## 🌟 意涵 DAC 2027 三大核心学术贡献支柱（The Three Pillars of GSG Architecture）

针对当前集成电路机器学习（ML-for-EDA）与图神经网络（GNN）十余年来在建模范式、深度过平滑以及全局图级池化上的理论死锁，意涵高瞻远瞩地确立了贯穿整篇 DAC 2027 顶级论文的三大核心理论支柱：

### 🏛️ 支柱一：边与关系的原生特征化（Native Relation-Centric Edge Dynamics）
- **传统局限**：过去的工作（如 GCN, GAT, DeepGate）普遍是“以节点为中心（Node-Centric）”的，将邻接矩阵退化为单纯的拓扑连通关系（0或1）或离散类别，忽略了导线和物理相互作用本身的丰富特征；
- **意涵破局**：在集成电路物理本质中，**金属导线从来不是抽象的连接，而是具有真实电阻、电容与物理做功阻抗的实体客体**！意涵坚决确立“关系即特征”原则，将连续物理阻抗（走线电阻 $R$、走线电容 $C$、通孔数、驱动负载电容 $C_{\text{load}}$、入度争夺）与拓扑类别深度解耦，作为一等公民直接参与相互作用做功，使铜互连线在图动力学中获得了与逻辑门完全平等的物理地位。

### 🏛️ 支柱二：图即集合，放弃消息传递，自由位移相互作用动力学（Graph-as-Set via Pairwise Displacement）
- **传统局限**：传统消息传递范式（MPNN）本质上是邻接矩阵上的高斯平滑滤波（Laplacian Smoothing），随着层数加深，狄利克雷能量指数衰减，不可逆地滑向均值，在 8~16 层必定遭遇严重的“过平滑（Over-smoothing）”与“过挤压（Over-squashing）”；
- **意涵破局**：
  1. **图嵌入升格为集合嵌入**：将图嵌入为一个集合作为目标，对集合建模本质上是对集合内部两两元素（Pairwise）相互作用的建模；
  2. **废除消息传递，代之以连续位移计算**：节点之间传递的不是“节点自身的静态画像”，而是两两之间相对物理差分与阻抗共同激发的**可学习位移做功微元 $\Delta s_{ji}$**；
  3. **去归一化自由演进与恒等残差流**：状态沿时间流形欧拉累加 $s_i^{(t+1)} = s_i^{(t)} + \Delta s_i$，输出层线性放行不加 tanh 截断，构建起跨越百层的“无衰减梯度高速公路”，使模型能轻松挺进到 **$T = 64 \sim 96$ 层** 而方差还原比依然保持在 **`0.983`**，因果相关性击穿 **`0.9541`**！

### 🏛️ 支柱三：虚节点分层电表网络，将全局聚合转化为可训练嵌入（Hierarchical Meters: Aggregation as Trainable Embedding）
- **传统局限**：在全图宏观 PPA（面积、功耗）预测中，传统全局平均/求和池化（Mean/Sum Pool）丢失局部异质性，而单虚节点全局汇聚则导致入度爆炸至 $O(N)$，使局部注意力权重被稀释为 $\frac{1}{N} \to 0$，造成严重的梯度堵塞与过平滑；
- **意涵破局**：
  1. **聚合问题转化为可训练嵌入问题**：通过引入虚节点（电表 Meter），将全局被动的信息汇聚升格为主动的局部微观粒子做功嵌入；
  2. **32-边平衡金字塔架构**：采用分支因子 $K=32$ 的多层级树状规约金字塔（Level-0 门级 $\to$ Level-1 局部电表 $\to$ Level-2 主电表 Root），使得金字塔中每一个节点的入度严格恒定为 $O(1)$（$\le 32$），计算规约复杂度降低至严格的 $O(\log_{32} N)$；
  3. **计算与硬件双重完美同构**：既在代数上同构了物理芯片的电源网格与时钟树分布，又完美对齐了 GPU Warp 的 32 线程单指令多线程（SIMT）并发，驱动全图总面积回归打出 **$R^2 = 0.9497, r = 0.9754$**、全图静态漏电打出 **$R^2 = 0.8400, r = 0.9282$** 的世界级精度！

## 核心算法主线四：32-边平衡分层电表金字塔（Hierarchical Meter Pyramid）与全图物理规约架构

- **意涵分层平衡规约理论（2026-11-09 创立）**：
  - **单点入度爆炸之殇**：若将全图成百上千个微观单元直接连接到单一电表节点，该电表的入度瞬间攀升至 $O(N)$，导致局部 Softmax 竞争发生极其严重的注意力稀释（每条入射边权重仅分得 $1/N$），且极易在单点产生信息过平滑；
  - **32-边平衡分层金字塔架构**：意涵提出构建类似芯片内部时钟树（Clock Tree）与电源网络（Power Grid）的多层级规约结构：
    1. **Level-0（微观单元层）**：全图所有的真实 Standard Cell 节点；
    2. **Level-1（局部微电表层）**：每 32 个微观单元汇聚到一个 L1 电表节点（边类型 14），进行局域物理做功提纯；
    3. **Level-2（顶层主电表 Root Meter）**：所有的 L1 电表节点汇聚至唯一的 Root 电表节点（边类型 15）；
  - **理论与硬件双重红利**：
    - **入度严格常数化**：金字塔中每一个节点的入度恒定小于等于 32，计算复杂度严格为 $O(\log_{32} N)$；
    - **GPU Warp 硬件原生对齐**：分支因子 $K=32$ 完美匹配现代 NVIDIA GPU 的 Warp 线程束大小，实现单指令多线程（SIMT）的无发散并行；
    - **全局无偏积分实测大捷**：在全图总面积上打出 $r=0.9754, R^2=0.9497, \text{MAPE}=7.75\%$，在全图纯静态漏电上打出 $r=0.9282, R^2=0.8400, \text{MAPE}=9.58\%$，彻底实证了图级物理规约的确定性法则！

- **意涵微观门弧（Cell Arc Delay）K-邻居微星团协同机制**：
  - **打破孤立双节点局限**：逻辑门的开关延迟受限于晶体管网络串并联的通断，单个输入引脚翻转时，强依赖同门其他同伴引脚（Sibling Pins）的偏置电平；
  - **K=6 微星团拓扑增强**：在动力学演化与 Pair 读出中，显式注入同一母门下的全部同伴引脚与直连走线真实 RC 负载电容（$C_{\text{load}}$），以 $O(N \cdot K)$ 的极低复杂度，轰出 $r=0.9630, R^2=0.9207, \text{MAE}=4.11\text{ ps}$ 的极值拟合！

## 核心算法主线三：CC-Tensor v3 原生紧凑整型嵌入查表与阻抗切片直连动力学架构

- **意涵“两点间信息传递成本为 $n$”因果光锥定理（2026-11-06 理论确立）**：
  - **物理世界拒绝超距瞬移**：在集成电路物理 DAG 中，信号波前必须沿着导线与逻辑门逐级传播，两个拓扑相距为 $n$ 的引脚之间，信息传递的刚性时间/步数成本严格等于 $n$；
  - **因果光锥刚性下界**：动力学演化步数 $T$ 直接决定了模型在图上的物理因果光锥半径。当 $T < n$ 时，下游引脚在数学上处于上游事件的因果光锥之外，绝无法超空间聚合信息；
  - **全景天梯单调实证**：消融实测证实，随着深度从 $T=8$ 逐步推进至 $T=96$，模型宏观单图拟合优度 $R^2_{\text{macro}}$ 从 $0.5249$ 单调暴涨至 $0.7262$，相关性 $r$ 从 $0.8393$ 攀升至 $0.9169$，直接用数据实证了拓扑长链因果推进的物理必然性。

- **意涵“可学习动态相互作用做功 vs 被动节点特征传递”范式革命（破解传统 GNN 深层死锁）**：
  - **传统消息传递（MPNN）为何无法维系深层训练？**
    1. **被动特征搬运死循环**：传统 GNN 传递的是节点自身的状态投影 $m_{j \to i} = W h_j$（像信使在搬运节点个人静态画像），多层叠加本质上是在邻接矩阵上做高斯平滑滤波，16 层后特征不可逆地滑向均值，狄利克雷能量衰减耗散诱发严重的“过平滑（Over-smoothing）”与“过挤压（Over-squashing）”；
    2. **物理逻辑错配**：集成电路中驱动端传递给接收端的从来不是“门本身的类型特征”，而是“电流对导线电容充放电所耗费的走线延迟与门翻转延迟微元（$\Delta \tau$）”；
  - **意涵相互作用动力学核心破局点**：
    1. **内容是“可学习的相对相互作用做功”，而非节点个人画像**：传递的内容是由两点相对空间差分、欧氏距离与电学阻抗共同激发的自由位移微元 $\Delta s_{ji} = \text{MLP}([s_j, s_i, s_j - s_i, \|s_j - s_i\|, r_{\text{feat}}])$；
    2. **状态沿时间流形欧拉累加，本征特征不被稀释**：节点更新方式为连续做功累加 $s_i^{(t+1)} = s_i^{(t)} + \Delta s_i$，构建起跨越近百层的无衰减恒等梯度高速公路；
    3. **STA 最坏路径排他性竞争阻断平滑**：通过局部 Softmax 竞争，权重几乎独占性地压在最慢主导路径上，彻底粉碎了传统 GNN 均权加和的特征退化，使得动力学即使挺进到 $T=96$ 极深层数，物理方差比 `std_ratio` 仍高达惊人的 **`0.948`**，MAE 压降至 **`41.6 皮秒`**！

- **消除 GPU 在线高频算力浪费（第一性原理）**：
  在深层动力学演化（$T=64$）中，高频前向循环中重复执行的 `argmax` 离散化、LUT 字典二次查表以及全图度数 `scatter_add` 重新统计，带来了大量无谓的计算开销与 CUDA 显存同步碎片。
- **原生整型直查（Native Integer Embedding Lookup）**：
  节点特征完全由离散紧凑通道表征：
  - 微观类别 `node_kind_id` $\in \{0..9\}$ 直接查表至 4 维嵌入；
  - 基础逻辑门 `node_base_id` $\in \{0..28\}$ 直接查表至 4 维嵌入；
  - 晶体管驱动强度倍率 `node_drive_val` $\in [0, 1]$ 线性升维至 4 维；
  - 引脚端口 `node_pin_id` $\in \{0..18\}$ 直接查表至 4 维嵌入；
  - 物理阻抗出度 $\log(1+\text{FanOut})$ 与入度 $\log(1+\text{FanIn})$ 各编码为 4 维；
  - 拼接形成极简、高凝聚的 **24 维平衡输入向量**，输入投影层 $O(1)$ 常数时间瞬时映射。
- **关系物理阻抗源宿索引切片直连（Zero-Storage Impedance Routing）**：
  边表仅存储紧凑关系类别 ID `edge_type_id` $\in \{0..13\}$。物理阻抗通道所需的源出度（驱动负载电容）与宿入度（扇入汇聚）无需在边表重复存储，在前向传播中直接通过源宿索引从节点张量切片收集：
  $$\text{rel\_impedance} = \big[\text{node\_log\_out\_deg}[\text{src}], \text{node\_log\_in\_deg}[\text{dst}]\big] \in \mathbb{R}^{E \times 2}$$
  经线性映射后与 6 维类别 Embedding 拼接为 **12 维纯净关系通道**，实现存储与显存的双重零浪费。
- **深层波前射程全图贯通（$T=64$ 长程演化）**：
  演化深度扩展至 $T=64$，打破深层逻辑链阻尼，结合 Cosine 学习率退火，驱动因果拓扑排序相关性稳定突破至 $r=0.9470$、全局决定系数跃升至 $R^2_{\text{pool}}=0.8621$。

## 核心算法主线二：V3.03 去归一化自由高维位移与精炼关系通道动力学体系（纯前向因果时间之箭 + 局部 Softmax 竞争汇聚）

- **数学隐空间自由位移哲学（意涵革命性第一性原理）**：
  - **超越自然界的引斥力束缚**：自然界中的力（万有引力、库仑力）受限于物理世界的空间一维连线，本质只能沿两点连线向量 $s_j - s_i$ 做拉近或推开（标量大小乘方向向量）；
  - **隐空间全向自由演化**：在神经网络展开的 32 维隐空间 $\mathbb{R}^{d_s}$ 中，位移根本不应拘泥于差分方向，而是由高维感知机直接映射出朝向空间任意方向、任意幅度的自由演化增量 $\Delta s_{ji}$：
    $$\Delta s_{ji} = \text{MLP}_{\text{free}}\big([s_j, s_i, s_j - s_i, \|s_j - s_i\|_2, r_{\text{feat}}]\big)$$
  - **彻底废除 `tanh` 归一化饱和**：输出层直接无界线性放行，彻底消除了极值区梯度死锁与模长压扁，让深层长链时序积分顺畅累加！

- **誓死捍卫“时间之箭”单向因果性（实测证伪反向边与随机伪边）**：
  - **DAG 波前推进的物理纯净性**：静态时序分析（STA）是严格单向的有向无环图因果累加，信号只能由上游驱动下游；
  - **实测消融铁证**：
    - 加入全图随机无连接边（$K=8$）导致拓扑相关性 $r$ 暴跌至 0.65（虚假噪声淹没因果）；
    - 加入反向链接边导致 $r$ 跌至 0.73（反向状态倒灌构成 2-Cycle 因果回路，导致时序波前发生双向驻波扩散平滑）；
  - **回滚纯前向因果骨架**：100% 保持有向单向边，负载电容反压完全内化为源节点的出度阻抗 $\log(1+\text{FanOut})$，确保波前单向锐利推进。

- **精炼关系双通道体系（解耦类别与阻抗，总维度 12 维）**：
  - **摒弃稀疏平铺，实现信噪比质变**：
    1. **拓扑类别通道（`rel_type_id`，仅 6 维紧凑 Embedding）**：将 14 种原始连接类型压缩为 6 维稠密特征，彻底消除 14 维稀疏 One-hot 的矩阵梯度稀释；
    2. **连续物理阻抗通道（源出度与宿入度，6 维线性映射）**：显式提供 RC 充放电阻抗标尺；
    3. **总维度仅 12 维**：高信噪比、极速运算，使网络对逻辑拓扑变化的敏锐度发生数量级跃迁！

- **局部 Softmax 极值竞争汇聚（同构 STA 最坏路径 Max 准则）**：
  - 流入同一宿节点的所有入射边，通过竞争 Logit 开展局部排他性 Softmax 竞争，权重和严格归一为 1：
    $$\Delta s_i = \sum_{j \in \text{FanIn}(i)} \text{Softmax}_j(c_{ji}) \cdot \Delta s_{ji}$$
  - 杜绝多扇入的平滑求和钝化，迫使网络挑选最慢主导时序路径！

- **历史性实测突破里程碑（2026-11-05 实测）**：
  - 拓扑排序相关性 $r$ 历史性突破至 **0.9115**（旧版 0.8578）；
  - 池化无偏决定系数 $R^2_{\text{pool}}$ 飙升至 **0.7692**（旧版 0.6156），单图宏观 $R^2_{\text{macro}}$ 达到 **0.7481**；
  - 物理到达时间 MAPE 降至 **16.04%**，真实方差还原比 `std_ratio` 达到近乎完美的 **0.983**！

- **时序物理第一性原理（绝对无作弊）**：
  - **断绝“层级（Level）与深度作弊”**：在因果时序（STA Arrival Time）建模中，拓扑深度/层级是图遍历搜索算法强加的外置标签，直接喂给网络等同于泄露路径答案；模型必须在“零层级、零作弊”状态下，完全凭借局部有向相互作用自发推演时序流；
  - **度数（Degree）的电学正名**：节点的出度（Fan-out）在半导体物理上就是驱动导线上所挂载的负载引脚总数，即**负载电容 $C_{\text{load}}$ 的直接物理代名词**；入度是扇入汇聚度。保留度数属于图论与电学内禀的合法特征，赋予每条有向边真实的 RC 做功阻抗。

- **意涵 DeepGate 式五大紧凑物理通道 Embedding 体系（粉碎稀疏噪音与死维度）**：
  - **摒弃一维一类的稀疏正交假设**：原本 63 维 One-hot 中存在 11 个从未出现过的死特征，且各类之间完全正交隔离、无法表达连续相似性，导致严重的注意力与梯度稀释；
  - **解耦为 5 大高信噪比物理通道（总维度 34 维，全稠密激活）**：
    1. **实体类别通道（`kind_id`，8 维嵌入）**：区分 `cell`, `cell_input_pin`, `cell_output_pin`, `net`, `port`；
    2. **母元门类型通道（`master_id`，16 维嵌入）**：刻画 `INV`, `NAND`, `DFF`, `XOR` 等门电路的固有物理驱动强度；
    3. **引脚端口通道（`pin_id`，8 维嵌入）**：区分 `A`, `A1`, `B`, `ZN`, `CK`, `D`, `Q` 等快慢输入与时钟端；
    4. **负载电容通道（出度 `log1p(out_deg)`，1 维标量）**：负载电容连续标尺；
    5. **汇聚争夺通道（入度 `log1p(in_deg)`，1 维标量）**：扇入汇聚争夺标尺；
  - 维度压缩 48%，有效信息密度暴增，消除了参数矩阵的空转。

- **意涵自适应时间片与选择性跳跃残差（Adaptive Time-Slice Residual Gating）**：
  - **离散时间片哲学**：将动力学 $T=32$ 步演化视作 32 个微观离散时间片；
  - **节点级按需早停与冲刺**：针对小图或浅层逻辑在第 15 步即可收敛、而大图深层逻辑需要更长推进的矛盾，由节点根据当前状态与受力，自主生成吸收门控 $\gamma_i^{(t)} \in (0, 1)$：
    $$s_i^{(t+1)} = s_i^{(t)} + \gamma_i^{(t)} \cdot \text{field}_i^{(t)}$$
  - 微观探针实证显示，节点累积活动步数与真实到达时间呈强正相关（$r = +0.5272$），浅层节点自发早停跳过多余位移，深层节点持续冲刺，有效攻破深层数值阻尼，全局池化 $R^2$ 大幅提升。

- **意涵向量敏感偏移计算（Vector-Sensitive Offset Direct Injection）**：
  - **打破非线性饱和致盲**：以往模型将差分向量打碎为标量欧氏距离并输入 tanh，导致只要差分模长大于 0.5 即可进入完全水平极值饱和区，无法对放大的输入差分做出比例响应；
  - **显式差分向量投影直通**：直接将唯一的空间差分向量 $\vec{\Delta}_{ji} = s_j - s_i$ 经正交投影层注入偏移算子：
    $$\vec{d}_{ji} = \mathbf{pair\_offset}_{ji} \cdot \alpha_{ji} = \tanh\Big(\mathbf{W}_{\text{vec}}(s_j - s_i) + \text{MLP}_{\text{sem}}(\text{pair\_input})\Big) \cdot \mathbf{Softplus}(\text{logit}_{ji})$$
  - 实测证实，输入向量扩大 10 倍时做功位移产生剧烈同向共振，彻底攻破几何模长不随时间拉长的死锁，在干净设计上推动池化 $R^2$ 跃升至 0.58。

- **直面端到端 Pin Timing 物理使命与相关性 $r$ 突破路径**：
  - **坚决拒绝退化为局部 Delay**：学术界部分方案退化为预测局部门延迟再调用传统图搜索，回避了多体动力学的核心难题；意涵确立最高纲领：全图节点直接预测真实引脚到达时间（Pin Arrival Time）；

## 核心算法主线一：V3.03 稀疏有界几何度量动力学体系（全实体密集化 + 节点独立投影 + 刚体不变性对数度量）

- **任务核心本质（第一性原理最高纲领）**：
  **当前芯片物理布局与度量任务在本质上，绝非将孤立节点属性做黑盒空间映射，而是“通过对多模态节点之间的相互作用（Pairwise Interaction）进行物理建模，让每个实体在动态位移与场演化中自发涌现空间结构与相对度量”。**
  - **坐标与相对距离是相互作用的涌现解**：单节点本身没有绝对坐标系，只有当它置身于其它节点构成的物理场中，通过拓扑相连节点的连线引力（Wirelength Attraction）、无连接单元间的占地排斥力（Density Repulsion）以及外部边界条件的共同作用，才能自发沉淀至稳定的低能态流形。

- **全实体（Cell / Pin / Net）物理坐标密集化推导原理（彻底打通拓扑绝缘断流）**：
  - **图论实体平等哲学**：在真实的物理芯片中，Cell 是门单元，Pin 是输入输出接口，Net 是导线介质，它们全都是物理图上平等的实体节点；
  - **Pin 归属物理继承**：每一个引脚 Pin 严格内嵌于所属 Cell 内部，其物理坐标直接继承所属 Cell 坐标：
    $$p_{\text{pin}} = p_{\text{cell}}$$
  - **Net 几何重心推导**：导线 Net 的宏观物理位置等于它所连接的所有已定位 Pin 的几何平均重心（Steiner 重心）：
    $$p_{\text{net}} = \frac{1}{|V_{\text{pin}}|} \sum_{k \in V_{\text{pin}}} p_k$$
  - **密集化覆盖效果**：无需重构磁盘数据集，在显存中毫秒级激活，使全图监督实体覆盖率瞬间从孤立的 **17% 暴增至 98.2%**，消除了中间 4 步跳跃的绝缘断流！

- **意涵节点独立 2D 投影与刚体不变性欧氏距离架构（消除旋转二义性与模式对抗）**：
  - **节点独立投影（MLP Node Projection）**：
    动力学演化终态 $s_i^{(T)} \in \mathbb{R}^{d_s}$ 经由内生独立读出头直接映射至 2D 物理空间：
    $$\hat{p}_i = \text{MLP}_{\text{node}}(s_i^{(T)}) \in \mathbb{R}^2$$
  - **显式无参数点对欧氏相对距离（E(2) Invariant Distance）**：
    两实体间的相对物理距离在投影坐标上直接显式计算，摒弃黑盒点对读出头，杜绝参数偷懒：
    $$\hat{d}_{ij} = \|\hat{p}_j - \hat{p}_i\|_2$$
  - **刚体旋转与平移不变性**：无论芯片版图是从左向右流（X 主导）、从下向上流（Y 主导）还是折返流，两两实体间的欧氏物理距离天然保持恒定，各芯片在独立坐标系中自由旋转，**全量跨芯片梯度 100% 同向共振，彻底消除了模式对冲崩塌**！

- **对数空间几何度量（Log-Distance Metric，克服微观尺度近视与除零发散）**：
  - **数学对等性**：对数空间下的绝对误差一阶展开严格等价于相对百分比误差（APE）：
    $$|\ln(\hat{d} + \epsilon) - \ln(d^* + \epsilon)| = \left|\ln\left(1 + \frac{\hat{d} - d^*}{d^* + \epsilon}\right)\right| \approx \frac{|\hat{d} - d^*|}{d^* + \epsilon}$$
  - **显微放大效应**：天然赋予微观微小距离（0.005~0.02 微米）与宏观距离平等的梯度纠错权重，有效驯服小尺度相对误差；
  - **抗除零发散**：引入芯片制造网格物理分辨率平滑基底 $\epsilon = 10^{-4}$，彻底杜绝几何重合点的除零爆炸假象。

- **意涵高密负采样力场（$\alpha=24$，构建 360 度全向无死角排斥力场）**：

- **微观局部误差与全局芯片尺度误差的统一数学定义**：

    $$\text{APE}_{ij} = \frac{|\hat{d}_{ij} - d_{ij}^*|}{d_{ij}^*}$$

### 2. 有界无连接长程相互作用（Bounded Implicit Interaction）算法机制

意涵指出，两两物理相互作用不应仅局限于有显式拓扑边的点对，更必须覆盖**无显式连接的点对**。在真实物理布局中，无连接单元间存在天然的**空间排斥力（Overlap Penalty / Density Repulsion）**与资源竞争场：

1. **相互作用的双重物理分解**：
   - **显式拓扑相互作用（Explicit Interaction, $\mathcal{E}$）**：沿着网络（Net）连接的单元传递弹性拉力（Attraction），实现线长收敛；
   - **无连接隐式相互作用（Implicit Interaction, $\mathcal{I}$）**：无直接连线的点对通过空间几何基底 $[s_j - s_i, \|s_j - s_i\|_2, s_j \odot s_i]$ 产生非局部排斥与疏解位移，驱动重叠消除与全局密度均衡。
2. **每个节点受力容量有界约束（Bounded In-degree Capacity, $K$）**：
   - 为避免全点对密集交互导致的 $O(N^2)$ 显存与计算瓶颈，为每个节点 $i$ 施加最大受力作用源上限 $K$：
     $$\mathcal{N}_K(i) = \mathcal{N}_{\text{explicit}}(i) \cup \text{Top-}(K - |\mathcal{N}_{\text{explicit}}(i)|)_{\text{implicit}}(i)$$
   - 每个节点 $i$ 至多聚合 $K$ 个最关键节点的作用力：
     $$s_i^{(t+1)} = s_i^{(t)} + \sum_{j \in \mathcal{N}_K(i)} (\text{gate}_{ji} \cdot \text{offset}_{ji}) + \text{noise}$$
   - 计算与显存复杂度由 $O(N^2)$ 严格坍缩至线性可扩展的 $O(N \cdot K)$，在大规模芯片图上自发维持动力学稳态并彻底消除 OOM 风险。

### 3. 物理增强轨道全节点全面展开分类（`G_place`, `G_route`, `G_rc`）

在物理实现与寄生提取阶段，所有新出现的物理节点必须全部展开为具体物理类别，杜绝粗糙分类：

- **物理单元（`physical_cell`，共 6 种具体物理 Master）**：
  - 时钟缓冲门：`physical_cell:CLKBUF_X2`, `physical_cell:CLKBUF_X3`
  - 驱动缓冲门：`physical_cell:BUF_X1`, `physical_cell:BUF_X2`, `physical_cell:BUF_X4`
  - 衬底接触保护单元：`physical_cell:TAPCELL_X1`
- **物理引脚（`physical_pin`，共 2 类）**：
  - 输入引脚：`physical_pin:A`
  - 输出引脚：`physical_pin:Z`
- **物理线网（`physical_net`，共 2 类信号类型）**：
  - `physical_net:CLOCK`（高优先级时钟物理网络）
  - `physical_net:SIGNAL`（常规物理信号线网）
- **布线几何金属段（`route_segment`，共 6 种具体金属层类别）**：
  - `route_segment:metal2`, `route_segment:metal3`, `route_segment:metal4`, `route_segment:metal5`, `route_segment:metal6`, `route_segment:metal7`
- **布线打孔过孔（`route_via`，共 7 种标准工件打孔类型）**：
  - `route_via:via1_4`, `route_via:via1_7`, `route_via:via2_5`, `route_via:via3_2`, `route_via:via4_0`, `route_via:via5_0`, `route_via:via6_0`
- **布线网络与端点（`route_net` 与 `route_endpoint`）**：
  - 布线网络：`route_net`
  - 布线引脚端点：展开为对应引脚类型或端口（共 18 种引脚端点）
- **寄生 RC 端点（`rc_endpoint`，共 2 大物理类别）**：
  - `rc_endpoint:pin_terminal`（已与标准单元引脚对齐的端点，保留具体的 `pin` 语义）
  - `rc_endpoint:internal_tap`（走线内部提取时产生的 RC 阶梯多边形抽头端点）
- **物理增强轨道拓扑关系与数值物理量**：
  - 拓扑关系边（10 类）：布线段连接、过孔连接、端点连接及物理引脚归属等。
  - RC 物理连续量边（4 类）：`resistor`（欧姆阻值 $R$）、`ground_capacitance`（对地电容 $C_{\text{gnd}}$）、`coupling_capacitance`（耦合电容 $C_c$）、`net_has_rc_endpoint`（RC 归属）。

## 图对学习契约

训练样本统一表示为：

```text
pair = (G, G', M_node, M_relation, C)
```

其中 `G` 是输入阶段图，`G'` 是对应输出阶段图，`M_node` 和 `M_relation` 是节点/关系映射，`C` 是工艺、时序和 flow 条件。模型学习 `G -> G'` 的结构、属性和新增实体变化；只有目标属性而没有 `G'` 的记录不作为主任务样本。

## 输入表示与分段特征编码契约

每个样本表示为带类型与属性的异构图：

```text
G = (V, E, Xv, Xe, C)
```

为精准对齐物理语义，节点特征 $X_v$ 采用**分段式双通道编码 (Split Dual-Channel Encoding)**：

1. **类别向量通道 (`cat_features`)**：
   - 包含 58 维离散 One-Hot 向量，严格承载微观节点类型（28 种 Cell Master、18 种 Pin Type、8 种 Port 语义、4 种 Net 扇出拓扑）。
2. **数值向量通道 (`num_features`)**：
   - 包含 $N$ 个连续物理标量（如：物理面积、几何长宽比、长宽绝对值等）。
   - **数值归一化规范**：所有几何空间数值（dbu）必须除以全局 `COORD_SCALE` ($400,000.0$) 进行 $[0, 1]$ 归一化，确保动力学场梯度演化的平稳性与可泛化性。
3. **拓扑度数与扇出提取的 $O(E)$ 极速建表机制**：
   - 为避免在确定 4 种 net 节点拓扑扇出时产生 $O(N_{\text{net}} \times |E|)$ 的二次方复杂度瓶颈，在特征张量提取前单次遍历边集合建立全局度数哈希表，实现 $O(1)$ 扇出类别检索，保证全量张量构建在毫秒级/秒级高效完成。
4. **跨阶段节点演化与掩码隔离机制**：
   - 针对 EDA 物理阶段注入的真实物理实体（如 `TAPCELL`、`BUF`、物理 pin 与物理 net），输入图保持原始逻辑网表大小 $N_{\text{in}}$；
   - 输出真实坐标通过唯一语义名称精准映射回原始逻辑标准单元，其余非目标节点在 `target_mask` 中严格置为 `False`，实现无偏净监督。

$V$ 是 cell、pin、net、port、library master、RC 等实体；$E$ 是 cell-pin、pin-net、driver-sink、timing arc、route、R、ground-C、coupling-C 等关系；$X_v$ 和 $X_e$ 分别保存离散类型和数值特征；$C$ 保存 library、PVT、SDC、clock、stage 与 corner 条件。输出图允许出现新增物理实体（如 route segment、via），必须在 mapping 中登记。

模型根据任务选用 `G_logic_pre_map`、`G_mapped_cellpin`、`G_place`、`G_gcell`、`G_route` 或 `G_rc`。任务读取逻辑、library、物理、时序和寄生条件，字段定义由数据集构造计划统一维护。

## 任务头

| 层级 | 图视图 | 输出 |
| --- | --- | --- |
| node | `G_mapped_cellpin`、`G_place` | cell area、static leakage、pin arrival/slack/slew、placement 坐标与状态 |
| relation | `G_mapped_cellpin`、`G_rc` | cell arc delay、sequential check、net delay、R、ground C、coupling C |

## 下游任务输入输出与工具链

意涵，任务头不能只接收一个脱离图结构的 label 文件；每个任务的输入图、输出图和匹配键固定如下：

### 基础网表轨道与寄生增强轨道

意涵，模型任务分成两类输入条件。基础网表轨道只使用逻辑网表、library、SDC 和已发生阶段的物理信息，适合 A1、S1、D1、P0、P1；寄生增强轨道使用 `G_route` 或 `G_rc`，适合 R1、D2、D3、P2。后布线 timing/QoR 目标必须绑定寄生增强图和对应条件，基础图只能用于 pre-route 预测。

| 输入轨道 | 输入图 | 目标类型 | 关键防泄漏规则 |
| --- | --- | --- | --- |
| 基础网表轨道 | `G_mapped_cellpin`、`G_place` | 面积、漏电、cell arc、placement、route/congestion 预测 | 不读取未来 `G_route/G_rc` 的 segment、via、R/C 和后布线 timing |
| 寄生增强轨道 | `G_route`、`G_rc` | RC 构造、net delay、pin timing、power/area/wirelength/QoR | 若目标是 R1，R/C 是输出；若目标是 D2/D3/P2，R/C 是已验收的输入条件 |

| 任务 | 输入图 | 输出图 | 主要工具产物 | 匹配键 |
| --- | --- | --- | --- | --- |
| A1/S1 | `G_mapped_cellpin` | 同拓扑 mapped 图，增加 area/leakage | Liberty、Yosys `netlist.json` | instance + master + PVT |
| D1 | mapped timing-arc 图 | 同一关系图，增加 cell arc/check | OpenROAD built-in STA + Liberty | from pin + to pin + arc type + condition |
| D2 | `G_route`/`G_rc` | 同一 net/route 图，增加 net delay | OpenRCX SPEF + OpenROAD wire timing edge | net + driver + sink + condition |
| D3 | `G_rc` | 同一 pin 图，增加 arrival/slack/slew | OpenROAD `report_checks` 与 pin timing | instance + pin 或 port + direction |
| R1 | `G_route` | `G_rc`，新增 RC 节点/关系 | OpenRCX `final.spef` | route terminal + SPEF node |
| P0 | `G_mapped_cellpin` | `G_place` | `3_place.odb`、placement export | instance + master |
| P1 | `G_place` | `G_gcell`/`G_route` | CTS/global route/detailed route ODB、DEF | 旧实体 key + 新实体 artifact key |
| P2 | `G_rc` | graph-output 图 | OpenROAD STA/power、Liberty、SPEF | design + stage + corner + mode |

固定中间链路为 `RTL -> Yosys netlist.json/netlist.v/stat.json -> OpenROAD ODB/DEF -> OpenRCX SPEF -> OpenROAD built-in STA/power -> graph extraction -> pair registry -> task registry`。物理阶段按 design 并行，图构造阶段按 design 可并行；manifest、registry 和任务清单由单一 supervisor 提交。独立 OpenSTA 仅作为已有工件的复核来源；其报告只有在写入 `output_graph` 并完成 mapping 后才可参与正式样本。

## 数据集使用

意涵，训练程序首先读取 `/data/yiyh/dac2027/dataset/circuit/circuitnet3_task_pairs_v1/manifest.json`，按任务记录获得 `input_graph`、`output_graph`、`track` 和状态；不直接把目录名或文件排序当作样本配对依据。

意涵，严格监督样本要求 `graph_valid_mask=true`、`target_valid_mask=true`、`status=pair_ready`，并且输入输出图、节点映射、关系映射、条件和 provenance 均存在。partial 样本需要 mask-aware loss；`source_pending`、`target_pending` 只作为未完成原因，不进入普通训练集。

意涵，2026-11-07 的寄生监督审计进一步区分“RC 图已存在”和“RC 目标可监督”：旧扩展张量中 D2/D3/R1/P2 的 mask 全 False，只能作为结构缓存；新的寄生轨道要求 D2 至少存在有效 `net_timing_target` 边，D3 至少存在有效 pin timing，P2 至少存在 area 或 STA/power 图级目标，R1 至少存在 route-to-RC 节点和关系映射。四个任务分别使用 edge-level、node-level、graph-level 和 graph-transformation 监督，不能用默认零值替代缺失工具观测。

意涵，P1 坐标预测使用节点级二维回归契约：输入为 `G_place`，输出为 route 阶段图，监督为对应逻辑 cell 的 `xy_target=[x_dbu,y_dbu]`。`xy_target_mask` 只对输入输出映射成功且坐标有效的节点通道置真；route 阶段新增的 physical cell 保留在输出图和 node mapping 中，但不反向伪造输入节点坐标。训练读取优先使用独立的 `xy_target` 字段，避免与 timing 的 arrival 通道混用。

意涵，split 以 `design_id` 为单位，避免同设计的不同阶段或不同任务跨 train/validation/test 泄漏；特征归一化和目标单位转换只使用训练 split 的统计量。基础轨道和寄生轨道分开训练或显式加入 `track` 条件，避免将后布线 RC 信息泄漏到 pre-route 任务。

## S1 概率桥与状态漏电标签契约

意涵，S1 数据层新增两个对齐监督通道：引脚/有效 cell 的 `signal_prob`，以及仅对 cell 有效的 `leakage_power`。primary input 的初始概率固定为 0.5，组合逻辑概率由 mapped DAG 和 Liberty pin direction 传播；每个 cell 的状态漏电由 Liberty `when` 条件概率与对应 leakage value 的加权和得到。该扩展只改变数据标签契约，不私自改变动力学模型。
## V3.04 S1 标签来源边界

意涵，V3.04 的数据构造只替换 S1 标签来源，不修改动力学模型。`signal_prob` 是 OpenROAD/OpenSTA activity 属性中的 duty 投影，`leakage_power` 是同一 activity 场景下实例级 `report_power` 漏电结果；两者都必须通过 valid mask 使用。当前实现不宣称工具提供了可直接读取的 `signal_probability` 字段，也不把未经验证的 BDD 精确相关性写入论文结论。
