# 试验记录
## 2026-10-26：V2 dense multi-hop 数据集与训练

- 新建 `dataset/v2_dense_multi_hop_directed/`，使用 DAC2027 timing graph topology 构造全有序 pair 标签；`max_nodes=512`，train/val/test=`1298/172/163`。
- 节点输入只保留 `node_kind/node_direction/node_cell_family/node_is_sequential`；不加入电气信息。
- 关系输入显式保存五类有向关系向量：`r_null`、`CELL_ARC_forward`、`CELL_ARC_reverse`、`NET_ARC_forward`、`NET_ARC_reverse`。
- 标签为 `reachable`、`min_hop`、`pair_valid` 和 `hop_valid`；构建不读取 delay/slack/criticality。构建脚本使用 8 个 CPU worker。
- `DenseMultiHopModel` 使用 V2 Evolution、节点对 `PAIRATTN`、`ENCR` relation state 和独立 relation head；`PAIRATTN` 不直接读取 relation vector。
- 完整 20 epoch 结果：valid reach accuracy `0.8475`、hop MAE `1.5925`。结果显示全局多跳关系可部分学习，但 reachability 和 hop 仍有明显误差。

## 2026-10-26：V2 单图 embedding 极端实验

- 固定单个 ADC_CTRL 图训练 1000 steps，排除跨 design 泛化影响，直接测试单图全局关系记忆能力。
- 最终 reach accuracy `0.8624`、hop MAE `1.0908`、reachable/unreachable embedding distance mean 为 `5.706/5.971`、distance-hop Pearson `0.5723`。
- 结论：节点 embedding 经 `PAIRATTN` 后可以编码部分有向多跳结构，但尚未达到完全记忆；embedding 欧氏距离仅作辅助诊断，不能替代有序 `PAIRATTN(i,j)` 读出。

### 方案1数据对齐规则

- `N_ep` 只包含合法 Launch endpoint 和 Capture endpoint；第一版限定 setup reg-to-reg，排除 CLK、RESET、unconstrained 和无法映射的路径。
- `Virtual Arc Delay` 和 `Path Criticality` 使用有序端点对；`[j,i]` 表示 launch `j` 到 capture `i`，不能强制对称。
- OpenSTA 只报告到的路径才进入 relation loss；没有标签的候选对保留 `has_label=false`，不填充零。
- `N_pin` 必须与 DAC2027 timing graph 的 pin 顺序一致；`N_cell`、`N_net` 只能在对应 physical artifact 中按 provenance 映射，不能跨视图直接复用端点。
- 阶段 2 数据目前尚未构造；在完成 DEF/ODB/SPEF、coverage、单位和 mask 审计前，不启动 physical-level 训练。

## 2026-10-26：Attn-Pair 自适应关系隔离版本

- 用户授权在保持宏观 `o(j,i)=f(r(j,i),pair(j,i),pos(j,i))` 的前提下自主优化必要算法细节；本版本将原先的基础 pair 运算升级为真正的 Attn-Pair。
- 实现目录：`test/v2_attn_pair/`，入口 `test/test_v2_attn_pair_isolation.py`；不依赖 `code/v2/`、`code/v1_c/` 或其他正式实现，暂不进入 `code/`。
- `SETATTN` 继续提供全局上下文 `H`；Attn-Pair 使用 `x_i=[s_i||H_i]`，目标查询 `q_i`、源键 `k_j` 和源值 `v_j`，计算多头 `score(j,i)`，在 source 维度做 masked softmax 得到 `alpha(j,i)`，再由 `PairEncoder(score, alpha, alpha*v_j, H_j, H_i)` 形成向量 `pair(j,i)`。

- 复杂度：QK、source softmax、value 广播和 pair encoding 均保持 dense `O(N^2)` 主项；没有加入全量三点中介重叠或矩阵值坐标。

- 当前状态：这是比 RPP 更完整的关系提取候选，但尚无训练性能结论。下一步使用相同真实图、相同初始化和 reachable-only 目标，与原 V2/RPP 做隔离对照。

## 2026-10-27：V2-EX 共享坐标动力学详细设计

- 用户要求先形成完整设计，再实现 v2-ex。详细设计写入现有 `具体设计.txt` 第 15 节，没有新增根目录文档。
- v2-ex 的核心数据流为 `G(X,R) -> S^(0) -> H^(t)=SETATTN(S^(t)) -> pair^(t)=AttnPair(H_j^(t),H_i^(t)) -> f(ENCR(r),pair,pos) -> S^(t+1) -> G'`。
- Attn-Pair 不再把 pair 当作 attention 对象；SETATTN 只对当前点集元素建立全局背景，pair 直接由 `H_j/H_i` 的有向投影、乘积、差分和值编码得到。关系输入第一版只在 `f` 中参与偏移条件。
- 坐标主路径移除 `LayerNorm(S+DeltaS)`；所有迭代步共享一套动力学参数，`T` 表示求解步数。最终状态是唯一训练监督，中间状态只记录 update/raw offset/noise/coordinate norm 和逐步关系指标。
- 噪声只用于早期对称性破除，并要求随对称性分数下降而退出；不把该过程定义为 diffusion。当前首轮数据契约为 V2 dense topology：4 维 topology-only 节点输入、5 类可数有向关系、显式 `r_null`、`max_nodes=512`。
- 当前状态：设计草案已完成，尚未实现 v2-ex 代码或正式训练；实现前必须先完成 `test/` 中的无 LayerNorm、共享参数、噪声退出、CUDA、padding 和同步排列 smoke。

## 2026-10-27：V2-EX Attn-Pair 多交互模式补充

- `AttnPair(H^t)` 不再限定为单一 `q_j*k_i`；设计新增 `diff`、`prod`、`sum`、source `value`、forward/backward 非对称门控和可选低秩 bilinear 模式。
- 第一版使用固定 `interaction_modes` 组合并记录在 config 中，建议默认 `diff+prod+value`；其它模式逐项消融。动态模式路由暂不进入第一版，避免模式权重塌缩掩盖单个交互模式的作用。
- 低秩 bilinear 只计算多个头内的投影点积，不构造完整外积；所有模式保持 source/target 有向投影和 dense `O(N^2)` 主复杂度。
- 该变化只更新 v2-ex 设计，不修改当前 `code/v2_ex` 实现；实现前需要重新完成自包含包的 smoke 和多步真实图对照。

## 2026-10-27：V2-EX 设计规范补充

- 根据后续讨论，v2-ex 设计已明确区分坐标主状态 `S` 与集合上下文 `H`：`S` 默认不使用 LayerNorm 或 RMSNorm；即使 H 分支采用上下文归一化，也不能写回 S。
- 设计补充了原因边界：LayerNorm 不必然抹掉所有长程信息，但会去除节点通道均值并重缩放通道方差，可能破坏坐标均值、模长和累计尺度；同时 `LayerNorm(S+DeltaS)` 不满足 `DeltaS=0` 时状态保持不变。
- 新增可选 graph-centering gauge：只减去全图中心，不缩放坐标并保持 `s_j-s_i` 不变；默认关闭，只有诊断确认共同平移漂移后才打开，并登记配置。
- 噪声调度改为显式单调包络 `sigma_i^(t+1)=min(sigma_i^(t), noise_max*c_i^(t+1))`；噪声退出与动力学收敛分开诊断。固定点要求无噪声时 `D_theta(S*,R)=0`，不能用步长变小代替 raw offset 变小。
- v2-ex 的验证要求更新为：无 LayerNorm/RMSNorm 坐标路径、共享动力学、噪声退出、graph-centering 差分保持性、CUDA、padding 和同步排列 smoke 后，才进入多步真实图对照。
