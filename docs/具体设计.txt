# 当前 V1 组件规格（与实现同步）

> 本文件描述当前主线 V1，不包含尚未实现的候选算子；V0 保留为无自适应噪声基线。目标是验证神经网络在给定
> 数据分布和固定点集维度下，能否近似保留图信息并生成与目标图相近的 `G'`，不宣称完全
> 还原或无损编码。

## 0. 输入与约定

- `X`：节点特征，形状 `[B, V, d_x]`。
- `R`：全关系张量，形状 `[B, V, V, d_r]`；`R[:, j, i]` 表示有向关系 `j -> i`。
- 所有节点对都有关系向量；无边是显式 `r_null`，不是 mask。`node_mask` 只处理 batch padding，`pair_mask[:, j, i] = node_mask[:, j] * node_mask[:, i]`。
- 合成实验使用连续节点和连续关系向量，节点/关系类型数均不适用且不可数。
- 真实分子实验将离散类别转换为 one-hot 连续输入：ZINC 为 21 类节点、3 类真实边、4 类
  稠密关系；QM9 为 5 类节点、3 类真实边、4 类稠密关系。第 0 类关系是显式 `r_null`，
  不属于 `node_mask` 或 `pair_mask`。

## 1. ENCS：节点预编码

```text
s(0, i) = ENCS(x(i)) = MLP_X(x(i))
```

输入 `X:[B,V,d_x]`，输出 `S(0):[B,V,d]`。当前实现为独立 MLP，不加入噪声或手工位置编码。
实现：`code/v0/encs.py`。

## 2. ENCR：关系预编码

```text
re(j, i) = ENCR(r(j,i)) = MLP_R(r(j,i))
```

输入 `R:[B,V,V,d_r]`，输出 `[B,V,V,d_p]`，供所有演化层使用。实现：`code/v0/encr.py`。

## 3. SETATTN：集合上下文

```text
Q = S W_Q, K = S W_K, V = S W_V
H = LayerNorm(S + softmax(QK^T / sqrt(d_h)) V W_O)
C = H + MLP_set(H)
```

padding 节点不参与 key/value 注意力，输出 padding 节点置零。当前为单头实现，作为
`PAIRATTN` 和终态解码的全局上下文。实现：`code/v0/setattn.py`。

## 4. PAIRATTN：有向点对探针

```text
C = SETATTN(S)
q_j = Linear_src(C_j), k_i = Linear_dst(C_i)
p_ji = MLP_pair(concat(q_j * k_i, q_j - k_i))
```

`p:[B,V,V,d_p]`，第 2 维为源节点 `j`，第 3 维为目标节点 `i`。源/目标投影不共享，
因此支持有向关系。演化探针只读取当前 `S`，不读取真实 `R`。实现：`code/v0/pairattn.py`。

## 5. ENCO、Gate 与逐层演化

```text
u_ji = ENCO(concat(p_ji, re_ji))
a_ji = pair_mask_ji * sigmoid(MLP_gate(concat(p_ji, re_ji)))
o_i = sum_j(a_ji * u_ji)
s(l+1,i) = LayerNorm(s(l,i) + o_i)
```

`a` 是标量软门控，`u` 与点集宽度相同；当前不除以 `V`，不宣称严格稀疏。每个
`EvolutionLayer` 独立拥有自己的 `PAIRATTN`、`ENCO`、`Gate` 和 `LayerNorm` 参数，默认
包含自关系，演化轮数 `L` 由 `layers` 控制。实现：`code/v0/enco.py`、`gate.py`、
`evolution.py`。

## 6. 终态解码与训练目标

```text
X' = NodeHead(SETATTN_out(S(L)))
R' = PAIRATTN_out(S(L))
L = L_node_mse + L_relation_mse
    + lambda_similarity * (1 - cosine(R', R_target))
```

终态 `SETATTN_out` 和 `PAIRATTN_out` 为解码器独立参数，均只读取 `S(L)`，不读取输入
`X` 或 `R`。当前连续 one-hot 实验使用 masked MSE 主项和可导关系余弦辅助项；准确率、
macro-F1 只用于评估，不参与梯度。当前 `lambda_similarity=0.1` 只是实验参数。
实现：`code/v0/decoder.py`、`loss.py`、`training.py`。

## 7. 训练闭环与输出

```text
batch = {nodes, relations, node_mask}
S(L), X', R' = V0Model(nodes, relations, node_mask)
loss.backward() -> AdamW.step()
```

`masked_mse` 只统计有效节点或有效节点对及其特征维度；`r_null` 不被 mask。训练脚本每
5 秒最多输出一行 batch 进度，并在 epoch 结束输出分项指标。合成入口为
`script/train_v0_reconstruction.py`，真实分子入口为 `script/train_v0_real.py`，真实图
转换为 `dataset/v0_real_molecule.py`。

## 8. 当前验证与效果

目标是验证 `S_e` 能否近似保留图信息并生成相近的 `G'`，不宣称完全还原。

### 8.1 当前真实 ZINC 效果

单种子、30 epoch、10,000/1,000 张 train/val 图、`lambda_similarity=0.1` 的 `layers=4`
实验达到验证节点 MSE `5.0271e-05`、关系 MSE `1.3426e-03`。使用 checkpoint
`runs/v0_real/zinc_layers4_similarity_best.pt` 在官方 test split 上评估得到：节点 accuracy
`0.999955`，全部关系 accuracy `0.995860`，真实边 accuracy `0.983878`，`r_null`
accuracy `0.997046`，关系 macro-F1 `0.985704`，边存在性 macro-F1 `0.987411`，MSE
`0.001309`。相较 `layers=2` 的真实边 accuracy `0.819735`，四轮演化显示出明显更强的
近似关系保持能力；这些结果仍不代表完全还原或跨数据集泛化。

### 8.2 当前阶段边界

- 当前只做单种子算法机制验证，暂不做多种子统计实验。
- `layers=4` 独立轮数实验已完成；不同轮数仍必须使用各自 checkpoint 评估。
- 尚未完成 QM9 正式训练、图级任务、基线比较或 `project/` 晋级。
- 评估入口：`script/evaluate_v0_real.py`；离散指标实现：`code/v0/evaluation.py`。

## 9. 初始噪声与对称性区分

### 9.1 核心问题

V0 与 V1 的 `ENCS` 都是确定性节点 MLP；V1 在逐层演化后加入自适应噪声。对于节点特征完全相同、且关系多重集在节点间
完全对称的图，`SETATTN`、`PAIRATTN` 和关系条件聚合都是置换等变的：对称节点会得到
相同的上下文、点对状态和聚合偏差。若终态点集中的节点仍完全相同，`PAIRATTN_out` 也
无法仅凭点对位置区分同一图内部的对称节点对。

例如，4 节点环和 4 节点全连接图都可以令节点特征相同。每个图内部的节点分别具有相同
的关系多重集；确定性消息聚合会保持节点间简并。关系类型数量不同可以区分两个图的整体
分布，但不能自动为对称图内部的节点建立唯一坐标，因此可能限制逐点关系矩阵的重构。

### 9.2 V1 噪声机制

可在初始点集加入微小随机节点标识：

```text
s(0, i) = MLP_X(x(i)) + epsilon_i
epsilon_i ~ N(0, sigma^2 I)
```

噪声使 `q_j`、`k_i` 和 `p_ji` 能够把局部关系与节点实例绑定，为对称结构提供隐式坐标，
从而可能降低关系重构中的对称性坍缩。它打破的是单次前向中的节点简并，不代表破坏图的
置换等变性或提供真实拓扑位置编码。

逐样本排列测试时，噪声必须随节点使用同一排列；如果每次前向独立重采样，只能讨论分布
意义上的等变性。噪声幅度 `sigma`、是否固定噪声和是否使用正交随机特征都属于新增实验
参数，已作为当前 V1 主线机制；V0 不包含该机制。

### 9.3 当前边界与实验顺序

- V1 不在 ENCS 初始输出直接加噪声，而是在每层关系演化后通过自适应噪声滤波器注入噪声；
  ZINC 结果只说明当前数据分布下近似关系恢复有效，不能推断所有强对称图都能恢复。
- 初始噪声应先在 `test/` 中使用 4 节点环、全连接图和其他可控对称图验证，再决定是否进入
  `code/v0/`。
- 实验需同时报告无噪声、固定同步噪声和独立重采样噪声的重构误差、关系类别指标、排列
  等变误差和跨随机种子方差。
- V1 已通过当前 smoke 和正式 ZINC 评估；V0 正式配置继续保留用于基线对照，两个版本均未进入 `project/`。

## 10. V1：逐层自适应噪声主线

V1 与 V0 分目录实现。V0 的关系演化结构保持不变，V1 在每个 `EvolutionLayer` 的状态
更新后增加独立的自适应噪声滤波器：

```text
c(l,i) = mean_j exp(-||s(l,i) - s(l,j)||^2 / temperature)
         , j != i, 且 j 为有效节点
sigma(l,i) = max_noise * c(l,i)
s_noisy(l+1,i) = s(l+1,i) + sigma(l,i) * epsilon(l,i)
```

当前 V1 使用有效节点间的高斯相似度均值作为聚拢程度；节点越聚拢，`sigma` 越大，节点越
分离，`sigma` 越小。`temperature`、`max_noise` 和噪声采样方式都是 V1 实验参数，不改变
V0 的已确认定义。

- V1 测试位置：`test/v1/`；正式位置：`code/v1/`。
- V1 每层独立创建演化模块和噪声滤波器，不共享 V0 参数；当前只复用 V0 算子类结构。
- 噪声必须在排列测试中随节点同步排列；padding 节点噪声为零。
- V1 已通过 CUDA、反向传播、聚拢/分离响应和同步噪声排列 smoke。
- 当前 V1 已完成一次单种子 ZINC 正式训练和 test 评估，现作为主线版本；V0 降级为稳定基线。
- V1 训练入口为 `script/train_v1_real.py`，评估入口为 `script/evaluate_v1_real.py`；评估使用
  固定 `noise-seed` 生成逐层噪声，保证同一 checkpoint 的结果可复现。
- V1 已完成一次单种子 ZINC `layers=4` 正式运行：节点 accuracy `0.999957`，全部关系
  accuracy `0.999067`，真实边 accuracy `0.994610`，`r_null` accuracy `0.999506`，关系
  macro-F1 `0.748045`，边存在性 macro-F1 `0.997654`，MSE `0.000488`。macro-F1 使用全
  test split 混淆矩阵计算；少数真实关系类别仍存在明显混淆。

## 12. 下游任务统一视角

V1 将节点级、关系级和图级任务统一放在以下数据流中：

```text
G(X,R) -> S_e -> G'(X',R') -> y_graph
```

目标图预测首先从 `S_e` 解码出节点特征 `X'` 和有序关系特征 `R'`；节点级任务评估 `X'`，
关系级任务评估 `R'`；图级任务通过
对节点状态、关系状态或其统计量进行置换不变聚合得到输出。图级任务不必逐项精确重构全部
关系，但任务所需的局部结构和全局统计信息必须先被编码进 `S_e`，再由聚合头形成图级表示。

因此，节点/关系预测本身就是目标图 `G'` 的组成部分，不是脱离图恢复的独立任务。节点/关系
近似恢复是 V1 验证目标图预测能力的基础实验，图级预测是 `G'` 或 `S_e` 之上的聚合读出，
而不是用一个未经解释的图级标量替代节点和关系信息。具体聚合器可以是 GCN 式消息聚合、
集合池化或其他置换不变读出，但必须明确其输入信息来自 `S_e`。

## 14. 电路表征建模实验任务
电路任务输入保持完整 `G=(X,R)`，不通过隐藏边或删除关系制造图任务。节点 area、internal power 和 leakage 等节点局部标签只作控制实验；graph area/total power 的节点求和只作聚合评估。
首要图敏感任务为：
1. 完整图级 QoR：Yosys/ABC mapped area、cell count、logic depth、OpenSTA WNS/TNS、critical path 和 timing violation；
2. 完整 timing graph 的 path-level arrival、required、slack、slew 和 criticality；
3. 多个综合 candidate 的 area/timing delta、QoR ranking 和 Pareto 选择；
4. Yosys equivalence/formal 驱动的电路功能和结构表示任务。
标签协议分为 synthesis-level 与 physical-level。前者使用 Yosys/ABC 和 OpenSTA；后者增加 OpenROAD floorplan/placement/CTS/routing、OpenRCX SPEF 和 post-route OpenSTA。power 必须登记 activity、corner、frequency 和 Liberty 条件；没有这些字段的结果不称为完整 PPA。

写成正式结论。

## 15.1 设计目标与边界

v2-ex 的目标是学习一个由完整图关系约束的自适应坐标动力学：

```text
G(X,R) -> S^(0) -> S^(1) -> ... -> S^(T) -> G'
```

其中 `S^(t)={s_i^(t)}` 是当前迭代时刻的点集状态。它不是人工位置编码，也不要求与外部
欧氏坐标逐点一致；有效性由最终从 `S^(T)` 读出的节点/关系任务和图重构质量判断。

v2-ex 不把增加层数本身称为扩散模型。它采用共享参数的确定性迭代动力学，并允许在早期
使用随机扰动打破完全对称节点的简并。只有显式定义前向噪声过程、时间条件目标和反向 score
监督后，才另行讨论真正的 diffusion 版本。

## 15.2 当前 V2 dense topology 数据契约

首个 v2-ex 验证任务沿用 `dataset/v2_dense_multi_hop_directed/`：

- 节点输入 `X` 宽度为 `d_x=4`，包含 topology-only 的
  `node_kind/node_direction/node_cell_family/node_is_sequential` 四个字段。字段的合法取值
  范围由数据构建 manifest 登记；模型不能把它们重新编码成不可解释的标签。
- 关系输入 `R` 宽度为 `d_r=5`，五种可数有向关系状态为
  `r_null/CELL_ARC_forward/CELL_ARC_reverse/NET_ARC_forward/NET_ARC_reverse`。
- `r_null` 是显式关系向量，不是 padding mask；四种有向 arc 状态保持方向独立。
- 输入 padding 由 `node_mask` 处理；有效节点对由
  `pair_mask[j,i]=node_mask[j]*node_mask[i]` 处理。padding 不能替代 `r_null`。
- 标签是全有序 pair 的 `reachable` 和可达 pair 的 `min_hop`。第一版主训练只使用最终任务
  标签，`min_hop` 用于逐 hop 诊断，不自动进入坐标动力学损失。

## 15.3 完整数据流和张量形状

```text
X              : [B,N,d_x]
R              : [B,N,N,d_r]
S^(t)          : [B,N,d_s]
H^(t)          : [B,N,d_s]
E=ENCR(R)      : [B,N,N,d_p]
pair^(t)       : [B,N,N,d_pair]
pos^(t)        : [B,N,N,d_s]
offset^(t)     : [B,N,N,d_s]
DeltaS^(t)     : [B,N,d_s]
```

```text
X,R
  -> ENCS(X) = S^(0)
  -> ENCR(R) = E
  -> for t=0,...,T-1:
       H^(t)       = SETATTN(S^(t), node_mask)
       pair^(t)    = AttnPair(H^(t), node_mask)
       pos^(t)     = S_j^(t) - S_i^(t)
       offset^(t)  = f(E, pair^(t), pos^(t), pair_mask)
       DeltaS^(t)  = aggregate_j(offset^(t))
       S^(t+1)     = S^(t) + eta * DeltaS^(t) + noise^(t)
  -> final SETATTN(S^(T)) and pair readout
  -> final node/relation task heads
```

`S^(t)` 是坐标主状态，`H^(t)` 是当前集合的全局背景。`H^(t)` 可以用于关系提取，但不能
覆盖或归一化写回 `S^(t)`，否则会破坏累计位移的尺度和固定点语义。

## 15.4 SETATTN：集合级全局背景

SETATTN 只把当前所有有效元素作为一个集合建模，不把 pair 当成新的 attention token：

```text
Q = S W_Q
K = S W_K
V = S W_V
A = softmax_j(Q_i K_j^T / sqrt(d_a))
H = S + (A V) W_O
```

`A` 的 source 维度只对有效节点归一化。padding key/value 在 softmax 前屏蔽，padding query
的输出最终置零。第一版不计算全量 attention 行重叠，也不引入三点 `O(N^3)` 中介计算；
全局中介信息通过 `H` 和后续迭代间接传递。

坐标主路径不使用 `LayerNorm(S+...)`，也不使用 `RMSNorm(S)`。LayerNorm 会去除每个节点
向量的通道均值并重新缩放通道方差；这不意味着所有长程信息必然消失，但会破坏可能编码在
坐标均值、模长和累计尺度中的信息，并且使 `DeltaS=0` 时仍可能改变状态。RMSNorm 去掉了
中心化但仍会缩放 `S`，因此也不能作为坐标主路径的默认替代。

SETATTN 的 `H` 是独立上下文分支。若为了 Q/K/V 或前馈计算进行 RMSNorm/其他有限值处理，
归一化结果只能留在 `H` 分支，不能写回 `S`。第一版优先使用无归一化的
`H=S+(AV)W_O`，将数值稳定性主要交给显式步长和初始化；上下文归一化是单独 ablation。

可选的全图平移 gauge 为：

```text
c^(t) = mean_i S_i^(t)
S_i^(t) <- S_i^(t) - c^(t)
```

该操作保持所有 `pos(j,i)=s_j-s_i` 不变，只移除整个点集的共同平移；它不缩放坐标，也不能
解决模长发散。第一版默认关闭，只有在诊断确认共同平移漂移影响数值范围时才打开，并在
config 中登记 `graph_centering=true`。

## 15.5 Attn-Pair：由 H 直接编码有序点对关系

v2-ex 中的 Attn-Pair 不再对 `pair(j,i)` 做第二次 attention。attention 已经在 SETATTN
阶段作用于集合；pair 阶段只使用上下文化后的两个元素 `H_j,H_i` 做有向关系编码：

```text
q_j = W_Q^src H_j
k_i = W_K^dst H_i
v_j = W_V^src H_j

pair(j,i) = PairEncoder(q_j * k_i, q_j-k_i, v_j, H_j, H_i)
```

source/target 投影不共享，`pair(j,i)` 和 `pair(i,j)` 可以不同。`v_j` 保留源点状态的
传递通道；`q_j*k_i` 提供跨投影子空间的匹配；`q_j-k_i` 提供有向差分；`H_j,H_i` 保留
集合上下文中的节点角色。

Attn-Pair 支持多个基础交互模式，不把所有关系表达能力压缩到单一的 `q_j*k_i`：

```text
m_diff(j,i) = q_j - k_i
m_prod(j,i) = q_j * k_i
m_sum(j,i)  = q_j + k_i
m_value(j,i)= v_j
m_fwd(j,i)  = sigmoid(A_fwd q_j) * k_i
m_bwd(j,i)  = sigmoid(A_bwd k_i) * q_j
```

低秩双线性模式作为可选模式加入：

```text
m_bilin^h(j,i) = (U_h q_j)^T (V_h k_i) / sqrt(d_h)
```

它使用多个小头表达跨通道耦合，不保存完整的 `q_j tensor_product k_i` 外积。所有模式
都由 source/target 非共享投影产生，并在 source-first 的 `[B,J,I,*]` 轴约定下计算。

第一版采用固定模式组合：

```text
z(j,i) = concat(
    m_diff, m_prod, m_value,
    optional(m_sum), optional(m_fwd), optional(m_bwd), optional(m_bilin)
)
pair(j,i) = PairEncoder(z(j,i), H_j, H_i)
```

`interaction_modes` 写入 config，用于固定消融和显存预算。建议首个默认组合为
`diff+prod+value`；方向门控和低秩双线性分别作为后续增量模式。动态模式路由不属于第一版
固定结构；后续若需要，令每个模式先投影到相同 `d_pair`，再使用归一化模式权重进行加权，
并单独诊断模式权重是否塌缩到单一分支。

所有上述模式仍是点对级基础运算，主复杂度保持 `O(N^2*d_pair)`；低秩双线性为
`O(N^2*heads*d_h)`，不引入全量三点中介张量或 `O(N^3)` 计算。

关系 `R` 第一版不直接进入 Attn-Pair，而是经过 ENCR 后在 `f` 中与隐式 pair 关系融合。
这样 `pair` 表示点集当前推断的关系，`R` 表示图中给出的显式关系，二者的一致化由坐标
动力学完成，避免 Attn-Pair 直接从输入关系走捷径。

## 15.6 相对位置与三模态偏移函数

```text
pos(j,i) = s_j - s_i
e(j,i)   = ENCR(r(j,i))
message  = MLP_f([e(j,i) || pair(j,i) || pos(j,i)])
route    = sigmoid(MLP_gate([e(j,i) || pair(j,i)]))
offset(j,i) = route(j,i) * message(j,i)
```

`route` 和 `message` 是同一个 `f` 模块的内部实现。`r_null` 仍是可学习关系状态，模型可以
学习其低贡献，但不能用硬编码 padding mask 把它删除。

## 15.7 共享坐标动力学与固定点

所有迭代步共享一套参数：

```text
D_theta(S^(t),R) = DeltaS^(t)
S^(t+1) = S^(t) + eta * D_theta(S^(t),R) + noise^(t)
```

`ENCR` 可以整图计算一次并跨步复用；SETATTN、Attn-Pair、`f` 和聚合规则在每个迭代步使用
相同参数。`T` 是求解步数，不是参数组数量。

无噪声时的理想固定点满足：

```text
D_theta(S*,R) = 0
S^(t+1) = S^(t) = S*
```

因此更新路径必须保持：

```text
S^(t+1) = S^(t) + eta_t * D_theta(S^(t),R) + epsilon^(t)
```

其中 `epsilon^(t)=0` 且 `eta_t>0` 时，`D_theta(S*,R)=0` 才是停止条件。任何在每步强制
重设节点均值或方差的操作都不属于 v2-ex 坐标动力学。

第一版使用有效节点平均聚合以减小不同 `N` 对偏移尺度的影响：

```text
DeltaS_i = sum_j pair_mask(j,i) * offset(j,i)
           / max(1, number_of_valid_sources(i))
```

`eta` 是外部步长，初始实验使用小的固定值。步长衰减属于稳定性实验参数，不能被误认为
模型已经找到固定点；实际偏移量和未乘步长的动力学量都必须记录。

## 15.8 对称性破除噪声

噪声只服务于完全相同或近似相同节点的早期对称性破除，不作为持续随机扩散过程：

```text
c_i^(t) = mean_{j != i} exp(-||s_i^(t)-s_j^(t)||^2 / temperature)
sigma_i^(t) = noise_max * c_i^(t)
epsilon_i^(t) = sigma_i^(t) * xi_i^(t)
```

padding 节点噪声为零。候选调度具体写为：

```text
sigma_i^(0)   = noise_max * c_i^(0)
sigma_i^(t+1) = min(sigma_i^(t), noise_max * c_i^(t+1))
epsilon_i^(t) = sigma_i^(t) * xi_i^(t)
```

当 `sigma_i^(t)` 低于登记的停止阈值时，该节点不再注入噪声。该单调包络是外部调度，不
改变 `f` 参数。训练和评估保存 noise seed；排列测试时噪声必须随节点排列同步。

噪声停止不等于坐标动力学收敛。诊断必须分别记录 `noise_norm` 与确定性
`eta*DeltaS_norm`。

## 15.9 最终监督与中间诊断

v2-ex 只对最终状态提供训练梯度：

```text
S^T -> final node/relation heads -> L_final
```

第一版不对中间状态增加辅助 loss，不对中间坐标施加人工轨迹标签。诊断记录：

```text
update_norm_t     = ||eta * DeltaS^(t)||_F / sqrt(N*d_s)
raw_offset_norm_t = ||DeltaS^(t)||_F / sqrt(N*d_s)
noise_norm_t      = ||epsilon^(t)||_F / sqrt(N*d_s)
coordinate_norm_t = ||S^(t)||_F / sqrt(N*d_s)
relation_metric_t = metric(Decode(S^(t)), target)
```

诊断分类为：

1. 正确收敛：update 后期趋小，noise 消失，raw offset 也接近零，最终关系指标稳定且有效。
2. 错误停滞：更新量趋小，但最终关系指标长期较差。
3. 振荡/发散：更新量反复增大或持续波动，坐标尺度增长，关系指标不稳定。

`raw_offset_norm` 不要求每一步严格单调下降；它必须在后期趋于零。只把 `eta_t` 变小而
没有降低 `raw_offset_norm`，只能说明外部步长停止了更新，不能判定动力学找到了固定点。

诊断指标不参与第一版训练 loss。只有确认系统能稳定演化后，才讨论稳定性正则。

## 15.10 最终读出与任务边界

```text
H^T       = SETATTN(S^T)
pair^T    = PairEncoder(H_j^T,H_i^T)
X'        = NodeHead(S^T,H^T)
R'        = RelationHead(pair^T)
```

最终读出不直接读取原始 `R`；原始关系只在坐标演化中作为条件输入。V2 dense reachability
可以用 `R'` 预测全有序 pair 的 `reachable`，用真实 `min_hop` 做分 hop 诊断。其他
query-conditioned head 必须单独登记其输入，不能把结果解释为纯坐标恢复能力。

## 15.11 复杂度、显存和执行边界

```text
SETATTN        O(N^2*d_s)
Attn-Pair      O(N^2*d_pair)
三模态 f       O(N^2*(d_p+d_pair+d_s))
source 聚合    O(N^2*d_s)
总计算         O(T*N^2)
```

不加入全量三点中介张量，因此不把复杂度提升到 `O(N^3)`。显存按 `T`、`N^2`、`d_s`、
`d_pair` 和 attention 中间状态记录。v2-ex 首轮只在 V2 dense topology 的 `max_nodes=512`
边界内验证，不能与 DAC V1-C 的 `max_nodes=2048` 边界混称。
